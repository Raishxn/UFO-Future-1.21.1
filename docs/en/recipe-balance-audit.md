# Recipe Balance and Coverage

UFO Future 3.0 rebalanced DMA and QMF recipes, component matrices, field generators, catalysts, stellar fragments and Infinity Cells. The older audit on this page counted recipe files and listed proposed changes from an earlier snapshot; those counts and costs no longer describe the current build.

## Current recipe layers

| Layer | Purpose |
|---|---|
| Standard crafting | Initial blocks, housings and support items |
| DMA | Flexible early and mid-game materials and components |
| Universal multiblocks | High-volume QMF, Slicer, Processor Assembler and Cryoforge work, gated by machine tier |
| Stellar Nexus | Expensive stellar simulations with fuel, coolant and heat management |
| Disassembly | Recover selected parts through separate recipes |

A higher MK machine runs lower-tier universal recipes faster and with less energy. The [multiblock tiers](multiblock-tiers.md) page gives the exact bonus. The [progression guide](progression.md) shows when to move between layers.

## Checking a recipe

Use JEI/EMI in the installed build for exact item and fluid amounts, energy, time and required tier. For scripted recipes, see [KubeJS recipes](kubejs-recipes.md). When upgrading a 2.x world, compare old AE2 patterns to current recipes and re-encode patterns whose inputs or outputs changed; see the [migration guide](../releases/MIGRATION_2.1-to-3.0.md).
