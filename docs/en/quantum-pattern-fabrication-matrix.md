# Quantum Pattern Fabrication Matrix

The **Quantum Pattern Fabrication Matrix** is a searchable AE2 pattern library and virtual assembler for crafting, smithing and stonecutting.

## Capacity and use

- Its **22 field positions** must use one consistent MK tier.
- Depending on field tier, the library holds **5,632 to 22,528 patterns**.
- Search and manage patterns through the controller interface.
- Connect it to the ME network for pattern-based automation.

The in-game structure preview shows the field layout. The [multiblock overview](multiblock-line.md) explains how this machine fits alongside the other crafting systems.
