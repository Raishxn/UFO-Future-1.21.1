# Quantum Computation Nexus

The **Quantum Computation Nexus** pools installed UFO crafting-storage and co-processor modules into shared AE2 crafting CPUs. Its available crafting capacity changes with the modules placed inside the structure.

## Modules and power

- Install UFO crafting-storage blocks to increase storage and UFO co-processors to increase parallel crafting capacity.
- **25 top-tier storage modules and 25 top-tier co-processor modules** unlock infinite compute mode.
- Nexus crafting uses no stored grid energy by default; the Grid Link still draws 32 AE/t. Operators can restore AE2's per-pattern cost and low-buffer throttling in `config/ufo/server.toml`.
- The Nexus does not take ownership of ordinary AE2 or other add-on CPU modules placed in its interior.

Check the controller and in-game structure preview for the live module count and placement.
