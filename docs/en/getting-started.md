# Getting Started

UFO Future 3.0 targets **Minecraft 1.21.1** on **NeoForge 21.1.x**. Check the current [release page](https://github.com/Raishxn/UFO-Future-1.21.1/releases) for a matching build.

## Required mods

- Applied Energistics 2 **19.2.17+** in the 19.x line
- RaishxCore **0.1.0-beta.2+** in the 0.1.x line
- AE2 Addon Lib **1.0.3-1.21.1+** in the 1.x line

Install all four JARs in the `mods/` directory. Mekanism is optional and enables chemical storage and recipes; JEI is recommended for recipe and multiblock previews. EMI, Applied Mekanistics and Applied Flux provide optional integration. UFO itself does not require GeckoLib.

## First steps

1. Power an AE2 network and craft the **Obsidian Matrix** and **Graviton Plated Casing**.
2. Build the [DMA](dma.md), connect it to AE2 and fill its coolant tank with **Gelid Cryotheum**.
3. Follow the [progression guide](progression.md) into stellar materials and the [multiblock line](multiblock-line.md).
4. Use JEI/EMI for exact recipes and the in-game structure preview or [Structure Scanner](tools.md) for multiblock placement.

## Existing worlds

Before loading a 2.1 world in 3.0, read the [migration guide](../releases/MIGRATION_2.1-to-3.0.md). Existing processing multiblocks need dedicated coolant and FE hatches, and the removed Entropic Assembler Matrix does not carry over. Test migration on a copy of the world.
