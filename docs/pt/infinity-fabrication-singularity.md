# Infinity Fabrication Singularity

A **Infinity Fabrication Singularity** e a maquina final de crafting agregado. Ela substitui o papel do antigo Quantum Crafter com rotas persistentes de producao.

## Producao

- Suporta ate **128 rotas persistentes de patterns**.
- Rotas ativadas repetem automaticamente; pedidos grandes executam as copias disponiveis no mesmo executor agregado.
- Conecte o **Quantum Grid Link** voltado para fora a rede ME.
- Alimente o **FE Energy Input Hatch** externamente. Somente o hatch de energia nao conecta a maquina a ME.

Use o controller para gerenciar patterns ativos e o preview para localizar o Grid Link e o hatch de energia.
