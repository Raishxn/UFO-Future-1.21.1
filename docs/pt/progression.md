# Progressao de crafting

Esta rota acompanha a linha atual de maquinas 3.0. **Use JEI/EMI para ingredientes, quantidades e energia exatos:** as receitas DMA e QMF foram rebalanceadas depois das antigas listas passo a passo.

## 1. Prepare a base

Monte uma rede AE2 alimentada, faca a **Matriz de Obsidiana** e a **Carcaca Graviton**, depois construa o [DMA](dma.md). O fluido da receita e o coolant ficam em tanques diferentes. Comece com **Gelid Cryotheum** e avance para Stable Coolant e Temporal Fluid conforme a producao crescer.

## 2. Faca materiais e componentes

Avance pelos fragmentos **White Dwarf → Neutron Star → Pulsar**. Use o DMA para componentes iniciais de processadores, matrizes e a cadeia de materia (**Proto → Corporeal → materias estelares → Dark Matter**). Consulte as receitas atuais no visualizador; ingredientes e quantidades mudam conforme o tier.

## 3. Automatize a linha de processamento

Construa o [QMF](quantum-matter-fabricator.md) para trabalho DMA em lote, o [Quantum Slicer](quantum-slicer.md) para partes impressas, o [Quantum Processor Assembler](quantum-processor-assembler.md) para processadores finais e o [Quantum Cryoforge](quantum-cryoforge.md) para materiais criogenicos. Suba os [tiers MK](multiblock-tiers.md) para liberar receitas e acelerar as anteriores.

Cada multibloco de processamento precisa de um **Pattern Buffer ou Proxy vinculado**, coolant externo no **ME Massive Fluid Hatch** e FE externo no **FE Energy Input Hatch**. Mantenha a rede ME alimentada separadamente.

## 4. Monte a producao endgame

Use o [Stellar Nexus](stellar-nexus.md) para simulacoes enormes. Adicione o [Quantum Computation Nexus](quantum-computation-nexus.md), a [Quantum Pattern Fabrication Matrix](quantum-pattern-fabrication-matrix.md) e a [Infinity Fabrication Singularity](infinity-fabrication-singularity.md) para trabalhos grandes de crafting AE2. A [Armadura UFO modular](armor.md), o Catalisador Dimensional e as [celulas avancadas](storage-cells.md) sao objetivos de longo prazo.

Vai atualizar um mundo antigo? Leia o [guia de migracao 2.1 → 3.0](../releases/MIGRATION_2.1-to-3.0.md) antes de reutilizar estruturas existentes.
