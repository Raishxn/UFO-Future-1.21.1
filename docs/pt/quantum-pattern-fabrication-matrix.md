# Quantum Pattern Fabrication Matrix

A **Quantum Pattern Fabrication Matrix** e uma biblioteca pesquisavel de patterns AE2 e montador virtual para crafting, smithing e stonecutting.

## Capacidade e uso

- Suas **22 posicoes de campo** precisam usar o mesmo tier MK.
- Conforme o tier dos campos, armazena **5.632 a 22.528 patterns**.
- Pesquise e gerencie patterns pela interface do controller.
- Conecte a maquina a rede ME para automatizacao por patterns.

O preview no jogo mostra a distribuicao dos campos. A [visao geral dos multiblocos](multiblock-line.md) explica o lugar desta maquina na linha de crafting.

A Matrix executa crafts iguais em lote e suporta até **16 / 32 / 64 lotes de receitas pendentes** com Fields MK1 / MK2 / MK3. Ela pode devolver essa quantidade de lotes ao armazenamento ME por tick. A velocidade efetiva depende das operações da CPU de crafting, dos ingredientes disponíveis, da energia da rede e do espaço para os resultados.
