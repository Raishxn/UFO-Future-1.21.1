# 工具与武器

UFO Future 的能量工具可在 **法杖、剑、镐、斧、锹、锄、锤、巨剑、钓竿和弓**之间切换，变形后保留储能。锤支持范围挖掘；镐与锤支持自动熔炼。

## 结构扫描仪

**结构扫描仪**除了旧版创造模式快速搭建功能，还提供完整的建造设置：

1. **对空气右键**打开设置，选择 **Scan（扫描）、Build（建造）、Replace（替换）或 Demolish（拆除）**模式，并设置接口安装与 MK1/MK2/MK3 力场等级。
2. 在 Scan 模式下**右键点击受支持的控制器**验证结构。扫描仪会报告缺失或错误的方块并高亮其位置。
3. 在建造模式下**潜行并右键点击控制器**启动所选操作。Build 和 Replace 会使用实际材料；扫描仪可准确返还被替换的方块。
4. 若要从 AE2 存储提取建造材料，请启用网络选项，并用扫描仪**右键点击 AE2 无线访问点**完成绑定。访问点与玩家必须位于同一已加载维度。

建造前可使用游戏内结构预览定位接口和力场位置。
