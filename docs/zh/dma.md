# 维度物质装配器（DMA）

**DMA** 是模组中的首台高级机器。它使用九格无序物品输入、可选配方流体和 AE2 网络供能，是多方块生产线之前的进阶起点。

## 输入与冷却

- **配方流体储罐**存放配方实际消耗的流体。
- **冷却液储罐**负责控制热量，与配方流体输入分开。
- **四个催化剂槽**可改变速度、能耗、热量和额外产物概率。参见[催化剂](catalysts.md)。

初期使用极寒冰晶，负载提高后升级到稳定冷却液和时间流体。机器工作时会产生热量；达到 50% 后进入危险区域，可能伤害没有[完整热防护护甲](armor.md)的附近玩家。达到最高温度后会启动五秒倒计时，随后发生破坏性故障。
