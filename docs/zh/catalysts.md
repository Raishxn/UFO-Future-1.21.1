# 催化剂

**DMA、QMF、量子切片机、量子处理器装配机和量子冷锻炉**均有四个催化剂升级槽。催化剂分为四个系列，每个系列有三个等级，另有维度催化剂。

| 系列 | 主要效果 | T1 / T2 / T3 |
|---|---|---|
| Matterflow | 降低配方能耗 | 每张卡 −10% / −25% / −50% |
| Chrono | 提高处理速度 | 每张卡 +25% / +62.5% / +125% |
| Quantum | 增加额外产物概率 | 每张卡 +10% / +25% / +50% |
| Overflux | 调整热量 | 静态热量为负；具体效果取决于控制器 |

Matterflow 和 Chrono 还分别为 T1 / T2 / T3 提供 **10 / 100 / 1000 倍**能量缓存倍率。组合高强度催化剂可能显著增加热量。四张完全相同的卡会触发系列协同效果，同时增加热量惩罚。

## Overflux 与热量

旧版 Wiki 声称 Overflux 会降低失败概率并主动冷却 DMA。当前加工代码没有对应的失败概率机制。DMA 会将每张卡的负热量贡献截断为零，因此 Overflux **不会主动冷却 DMA**。并行多方块机器会将其负值计入总热量倍率；四张 Overflux 卡可进一步降低倍率。

## 维度催化剂

尽管旧版提示称其为“创造模式催化剂”，它实际上是**可通过 MK3 QMF 配方制作的物品**。它大幅加速加工、消除处理能耗与热量，并保证额外产物。**配方原料仍会消耗。**请在 JEI/EMI 中查看当前的高成本配方。

长期自动化前，可通过控制器状态界面确认催化剂组合后的速度、能耗和热量。
