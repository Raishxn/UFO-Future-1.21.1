# 多方块等级

通用多方块机器共用 **MK1 / MK2 / MK3** 等级系统，用来限制配方并提升效率。

## 配方解锁

- **MK1** 机器：只能执行 MK1 配方。
- **MK2** 机器：可以执行 MK1 和 MK2 配方。
- **MK3** 机器：可以执行 MK1、MK2 和 MK3 配方。

机器等级低于配方要求时，控制器不会启动该配方。

## 等级加成

高级机器执行低等级配方时会自动获得效率加成。每高出一个等级：

- **处理时间**减半。
- **AE 能耗**降为原来的 **75%**。

例如：

- MK2 机器执行 MK1 配方：速度提高 **2 倍**，AE 能耗降低 **25%**。
- MK3 机器执行 MK1 配方：速度提高 **4 倍**，AE 能耗降低 **43.75%**。

## 升级的意义

即使暂时不制作新配方，升级机器也能加快现有生产线。当 AE2 通过量子样板缓冲器或代理向同一控制器派发大量任务时，这项加成尤其有用。
