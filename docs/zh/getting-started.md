# 入门指南

UFO Future 3.0 适用于 **Minecraft 1.21.1** 与 **NeoForge 21.1.x**。请从[发布页面](https://github.com/Raishxn/UFO-Future-1.21.1/releases)下载兼容版本。

## 必需模组

- Applied Energistics 2 **19.2.17+**，限 19.x 系列
- RaishxCore **0.1.0-beta.2+**，限 0.1.x 系列
- AE2 Addon Lib **1.0.3-1.21.1+**，限 1.x 系列

将 UFO 与以上三个模组的 JAR 一同放入 `mods/`。Mekanism 为可选依赖，提供化学品存储和相关配方；建议安装 JEI 查看配方和多方块预览。EMI、Applied Mekanistics 和 Applied Flux 提供可选集成。UFO 本身不要求 GeckoLib。

## 初期步骤

1. 建立有电的 AE2 网络，制作**黑曜石矩阵**和**引力子镀层外壳**。
2. 建造 [DMA](dma.md)，连接 AE2，并在冷却液储罐中加入**极寒冰晶**。
3. 按[进阶指南](progression.md)制作恒星材料并进入[多方块生产线](multiblock-line.md)。
4. 在 JEI/EMI 中核对准确配方；用游戏内结构预览或[结构扫描仪](tools.md)搭建多方块机器。

## 旧世界升级

将 2.1 世界升级至 3.0 前，请阅读[迁移指南](../releases/MIGRATION_2.1-to-3.0.md)。现有加工多方块机器需要专门的冷却液与 FE 接口，已移除的 Entropic Assembler Matrix 无法保留。请先在世界副本中测试升级。
