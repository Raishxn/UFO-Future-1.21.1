# 量子计算枢纽

**量子计算枢纽（Quantum Computation Nexus）**将 UFO 合成存储器和协处理器模块组合成共享的 AE2 合成 CPU。实际容量由结构内安装的模块决定。

## 模块与能源

- 安装 UFO 合成存储器可增加容量；安装 UFO 协处理器可提高并行能力。
- 安装 **25 个最高等级存储模块和 25 个最高等级协处理器模块**可解锁无限计算模式。
- 默认情况下，枢纽合成不消耗网络储能；量子网格链接仍需要 32 AE/t。服务器管理员可在 `config/ufo/server.toml` 中恢复 AE2 的每配方能耗和低储能限速。
- 枢纽不会占用放在内部的普通 AE2 或其他附属模组 CPU 模块。

通过控制器和游戏内结构预览查看模块数量及正确位置。
