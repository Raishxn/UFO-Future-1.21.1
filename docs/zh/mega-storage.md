# 巨型存储

UFO Future 为 AE2 合成系统增加了超大容量的合成存储器和巨型协处理器。

## 巨型合成存储器

模组提供容量逐级提升的存储方块，用于规模庞大的自动合成任务：

- 事件视界合成存储器（Event Horizon）
- 量子驱动矩阵合成存储器（Quantum Drive Matrix）
- 超立方体单元合成存储器（Tesseract Unit）
- 维度存储立方体合成存储器（Dimensional Storage Cube）
- 超高密度恒星合成存储器（Hyper-Dense Stellar）

## 巨型协处理器

巨型协处理器提高 AE2 同时调度任务的能力：

- 奇点加速器（Singularity Accelerator）
- 量子比特协处理器（Qubit Co-Processor）
- 超立方体逻辑单元（Tesseract Logic Unit）
- 子空间协处理器（Subspace Co-Processor）
- 银河核心协处理器（Galactic Core Co-Processor）

## 进阶中的作用

这些方块与 DMA 和多方块机器配合使用：

- **DMA** 和 **QMF** 生产许多高级部件。
- **量子多方块机器**以工厂规模执行配方。
- 巨型存储硬件使大型 AE2 合成任务持续运行。
