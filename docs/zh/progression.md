# 合成进阶

本路线对应当前 3.0 机器体系。**请以 JEI/EMI 显示的原料、数量和能耗为准：**旧版分步列表写成后，DMA 与 QMF 配方已经重新平衡。

## 1. 建立基础

搭建有电的 AE2 网络，制作**黑曜石矩阵**与**引力子镀层外壳**，然后制造 [DMA](dma.md)。配方流体与冷却液使用不同的储罐。先使用**极寒冰晶**，随着产量增加升级到稳定冷却液和时间流体。

## 2. 制作材料和组件

依次获取**白矮星 → 中子星 → 脉冲星**碎片。使用 DMA 制作初期处理器部件、组件矩阵，并推进物质链（**原始物质 → 实体物质 → 恒星物质 → 暗物质**）。不同等级的原料和数量有所变化，请查看游戏内当前配方。

## 3. 自动化加工生产线

建造 [QMF](quantum-matter-fabricator.md) 批量执行 DMA 类任务，用[量子切片机](quantum-slicer.md)制作印刷部件，用[量子处理器装配机](quantum-processor-assembler.md)完成处理器，再用[量子冷锻炉](quantum-cryoforge.md)生产低温材料。提升 [MK 等级](multiblock-tiers.md)可解锁新配方并加快旧配方。

每台加工多方块机器都需要一个**量子样板缓冲器或已连接的代理**、通过 **ME Massive Fluid Hatch** 外部供应冷却液，以及通过 **FE Energy Input Hatch** 外部供电。ME 网络需独立供电。

## 4. 建立终局生产

使用[恒星枢纽](stellar-nexus.md)执行大规模模拟。再加入[量子计算枢纽](quantum-computation-nexus.md)、[量子样板制造矩阵](quantum-pattern-fabrication-matrix.md)与[无限制造奇点](infinity-fabrication-singularity.md)承担大型 AE2 合成任务。[模块化 UFO 护甲](armor.md)、维度催化剂和[高级存储单元](storage-cells.md)是长期目标。

升级旧世界前，请阅读 [2.1 → 3.0 迁移指南](../releases/MIGRATION_2.1-to-3.0.md)，再复用原有结构。
