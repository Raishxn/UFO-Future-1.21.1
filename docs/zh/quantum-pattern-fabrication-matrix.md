# 量子样板制造矩阵

**量子样板制造矩阵（Quantum Pattern Fabrication Matrix）**是可搜索的 AE2 样板库，也是支持合成、锻造和切石的虚拟装配器。

## 容量与使用

- **22 个力场位置**必须使用相同的 MK 等级。
- 随力场等级变化，可存储 **5632 至 22528 个样板**。
- 可在控制器界面搜索和管理样板。
- 连接 ME 网络以使用样板自动化。

游戏内结构预览会显示力场布局。[多方块系列概览](multiblock-line.md)介绍它在合成系统中的位置。

Matrix 批量执行相同的合成。使用 MK1 / MK2 / MK3 Field 时，最多支持 **16 / 32 / 64 个待处理配方批次**，每 tick 可将同等数量的批次送回 ME 存储。实际吞吐量取决于合成 CPU 操作数、原料、网络能量和输出存储空间。
