# 无限制造奇点

**无限制造奇点（Infinity Fabrication Singularity）**是终局聚合合成机器，以持久化生产路线承担旧版 Quantum Crafter 的角色。

## 生产方式

- 最多支持 **128 条持久化样板路线**。
- 启用的路线会自动重复；大型请求通过同一个聚合执行器处理所有可用份数。
- 将朝外的 **Quantum Grid Link** 连接到 ME 网络。
- 从外部为 **FE Energy Input Hatch** 供电。仅连接能量输入仓无法接入 ME。

通过控制器管理启用的样板，并使用结构预览定位 Grid Link 和能量输入仓。
