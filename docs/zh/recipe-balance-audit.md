# 配方平衡与覆盖

UFO Future 3.0 重新平衡了 DMA 和 QMF 配方、组件矩阵、力场发生器、催化剂、恒星碎片及 Infinity Cells。旧版审查曾统计当时的配方文件并提出修改建议；那些数量和成本已不代表当前版本。

## 当前配方层级

| 层级 | 用途 |
|---|---|
| 普通合成 | 初期方块、外壳和辅助物品 |
| DMA | 初期至中期的灵活材料与组件加工 |
| 通用多方块机器 | QMF、切片机、处理器装配机和冷锻炉的大批量加工，受机器等级限制 |
| 恒星枢纽 | 需要燃料、冷却液与热量管理的高成本恒星模拟 |
| 拆解 | 通过独立配方回收部分组件 |

高级 MK 机器执行低等级通用配方时速度更快、能耗更低。具体加成参见[多方块等级](multiblock-tiers.md)，阶段顺序参见[合成进阶](progression.md)。

## 核对配方

请在当前安装版本的 JEI/EMI 中查看准确的物品和流体数量、能耗、时间与所需等级。脚本配方参见 [KubeJS 指南](kubejs-recipes.md)。从 2.x 世界升级时，应核对旧 AE2 样板并重新编码输入或产出已变化的配方；参见[迁移指南](../releases/MIGRATION_2.1-to-3.0.md)。
