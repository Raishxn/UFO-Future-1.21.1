# 量子处理器装配机

**量子处理器装配机**是处理器生产线的最终多方块机器。它使用印刷电路及辅助材料，大规模组装终局处理器。

## 主要功能

- 标准模式最多运行 **27 个并行任务**
- 安全模式运行 **9 个并行任务**
- 支持通用多方块配方
- 通过**量子样板缓冲器**或已连接的**量子样板代理**接入 AE2 自动合成
- 直接从网络提取原料，并将产物送回网络

## 量子样板缓冲器与代理

- 结构必须安装且仅安装一个缓冲器或代理。
- 缓冲器最多存储 **72 个编码样板**；已连接的代理可共享另一个缓冲器。
- 每个样板任务只占用一个空闲线程，不会阻塞整台机器。

## 工厂生产链

- **量子切片机**制作印刷部件
- **量子处理器装配机**完成处理器组装
- **QMF**负责高负载的 DMA 类物质加工
