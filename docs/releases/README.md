# Histórico de releases

Este diretório preserva changelogs e textos publicados em releases antigas.
`CHANGELOG.md` é o índice histórico principal; os arquivos `UPDATE_LOG_*` são
snapshots de publicações anteriores e não participam do runtime nem do JAR.

O resumo técnico da correção 3.0 está em
[CHANGELOG_L0001_L0037.md](CHANGELOG_L0001_L0037.md).

Novas alterações devem ser registradas no changelog principal. Um novo arquivo
por plataforma só deve ser criado quando o formato de publicação exigir conteúdo
materialmente diferente.
