# Progresion de crafting

Esta ruta sigue la linea actual de maquinas 3.0. **Usa JEI/EMI para ingredientes, cantidades y energia exactos:** las recetas DMA y QMF se rebalancearon despues de las antiguas listas paso a paso.

## 1. Prepara la base

Crea una red AE2 alimentada, fabrica la **Matriz de Obsidiana** y la **Carcasa Graviton**, y construye el [DMA](dma.md). El fluido de la receta y el coolant van en tanques distintos. Empieza con **Gelid Cryotheum** y avanza hacia Stable Coolant y Temporal Fluid cuando aumente la produccion.

## 2. Fabrica materiales y componentes

Avanza por los fragmentos **White Dwarf → Neutron Star → Pulsar**. Usa el DMA para piezas iniciales de procesadores, matrices y la cadena de materia (**Proto → Corporeal → materias estelares → Dark Matter**). Consulta las recetas actuales en el visor; los ingredientes y cantidades cambian segun el nivel.

## 3. Automatiza el procesamiento

Construye el [QMF](quantum-matter-fabricator.md) para trabajo DMA en lote, el [Quantum Slicer](quantum-slicer.md) para piezas impresas, el [Quantum Processor Assembler](quantum-processor-assembler.md) para procesadores finales y el [Quantum Cryoforge](quantum-cryoforge.md) para materiales criogenicos. Mejora los [niveles MK](multiblock-tiers.md) para desbloquear recetas y acelerar las anteriores.

Cada multibloque de procesamiento necesita un **Pattern Buffer o Proxy vinculado**, coolant externo en el **ME Massive Fluid Hatch** y FE externo en el **FE Energy Input Hatch**. La red ME necesita energia por separado.

## 4. Produccion final

Usa el [Stellar Nexus](stellar-nexus.md) para simulaciones enormes. Incorpora el [Quantum Computation Nexus](quantum-computation-nexus.md), la [Quantum Pattern Fabrication Matrix](quantum-pattern-fabrication-matrix.md) y la [Infinity Fabrication Singularity](infinity-fabrication-singularity.md) para grandes trabajos de crafting AE2. La [Armadura UFO modular](armor.md), el Catalizador Dimensional y las [celdas avanzadas](storage-cells.md) son objetivos a largo plazo.

Si actualizas un mundo antiguo, lee la [guia de migracion 2.1 → 3.0](../releases/MIGRATION_2.1-to-3.0.md) antes de reutilizar estructuras.
