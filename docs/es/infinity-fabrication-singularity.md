# Infinity Fabrication Singularity

La **Infinity Fabrication Singularity** es la maquina final de crafting agregado. Sustituye el papel del antiguo Quantum Crafter con rutas persistentes de produccion.

## Produccion

- Admite hasta **128 rutas persistentes de patrones**.
- Las rutas habilitadas se repiten automaticamente; los pedidos grandes ejecutan las copias disponibles mediante el mismo ejecutor agregado.
- Conecta el **Quantum Grid Link** orientado hacia fuera a la red ME.
- Alimenta el **FE Energy Input Hatch** externamente. El hatch de energia por si solo no conecta la maquina a ME.

Usa el controlador para administrar patrones activos y la vista previa para localizar el Grid Link y el hatch de energia.
