# 高容量存储元件

欢迎了解 **UFO Future** 的元件存储技术！
我们的存储元件超越了原版 Applied Energistics 2 的容量，打破标准位限制，可容纳天文数字级别的物质。

## 多级宇宙元件

这些元件由高强度的星体物质锻造而成，因此拥有极高的字节容量！
每种元件都能存储超大容量的物品/流体，不同颜色的 LED 核心标示其等级。

- **40M 元件** *（回响核心）*：由白矮星组件锻造
- **100M 元件** *（信标核心）*：基础超致密网络
- **250M 元件** *（联结核心）*：进阶四维超立方机制
- **750M 元件** *（核心）*：巨型视界地平线封存
- **奇点元件** *（绿色核心）*：借助宇宙弦实现近乎无限的 65k 类型存储。

## 流体宇宙元件

与物品组件类似，流体元件采用深蓝色的**中子星外壳**，专为长期维持极端流体温度而不损失完整性而设计。

**无限元件**是终局造物，代表着物质操控的绝对巅峰。一旦制成，它们会直接将某种资源的**近乎无限的数量**注入你的网络，而不会占用实际存储空间。

### 制造流程
无限元件**只能在次元物质装配器（DMA）中制造**！
锻造无限物质所需的巨大压力要求极端条件：
1. 获得一个**宇宙弦组件**和一个**量子异常**。
2. 供应大量原材料（例如 64 个水桶、64 个圆石）。
3. 注入**超越物质流体**。
4. DMA 会将奇点合成为稳定的永久节点。
