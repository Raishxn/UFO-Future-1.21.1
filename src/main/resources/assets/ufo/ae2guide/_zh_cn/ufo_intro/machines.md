# 机器

UFO 的生产由职责不同的机器共同完成。DMA 灵活而紧凑；通用多方块机器增加了 AE2 样板派发和并行处理；
恒星联结则负责耗时且昂贵的终局模拟。

<SubPages />

## 通用控制器操作

- **扫描**：检查结构，并报告缺失或无效的位置。
- **安全模式**：将并行上限限制为 9，并在达到温度上限时停止工作。
- **超频**：提高每 tick 的处理进度，但会产生多得多的热量。
- 进程页面最多显示 27 个独立任务。暂停只影响所选进程，不会清除其输入、能量或进度。

## 常见运行状态

| 状态 | 含义 | 首先检查 |
|---|---|---|
| `UNFORMED` | 结构不匹配 | 运行扫描并检查高亮方块 |
| `PAUSED_NO_GRID` | 没有可用且已供电的 AE2 节点 | 线缆连接面、频道和网络供电 |
| `IDLE` | 已成型并联网，但没有可运行任务 | 样板和配方等级 |
| `RUNNING` | 至少一个线程正在运行 | 温度和输出容量 |
| `OUTPUT_BLOCKED` | 完成的产物无法进入存储 | 释放 ME 存储空间或修复输出连接 |
| `INVALID_RECIPE` | 已保存进程无法再解析配方 | 数据包/重载以及返还流程 |
