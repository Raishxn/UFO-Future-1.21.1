# 多方块等级

通用多方块使用共享的 **MK 等级**体系。

## 配方锁定
- **MK1** 控制器运行 MK1 配方。
- **MK2** 控制器运行 MK1 和 MK2 配方。
- **MK3** 控制器运行 MK1、MK2 和 MK3 配方。

如果机器等级低于配方等级，配方将保持锁定。

## 等级加成
当更高等级的多方块运行较低等级的配方时，它会获得自动缩放：

- **时间**：每高出一级，时间减半。
- **能量**：每高出一级，能量消耗降低至 **75%**。

示例：
- MK2 机器运行 MK1 配方 = **2 倍速度**和**减少 25% 能量**
- MK3 机器运行 MK1 配方 = **4 倍速度**和**减少 43.75% 能量**

## 为何如此重要
升级等级不仅仅是为了解锁新配方。它还能把旧生产线压缩为快得多的后台吞吐。

这正是后期基地能够在玩家转向更繁重的模拟和多方块自动化时，让较旧的产业链继续运转的原因。
