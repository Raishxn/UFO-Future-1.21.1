# QMF 操作与配方

QMF 既能执行原生 QMF 配方，也能执行兼容的 DMA 配方。在提交任何资源前，
系统会先检查机器等级是否满足配方要求。

## 启动检查表

1. 确认显示 **FORMED** 和 **GRID ONLINE**。
2. 确认显示的 MK 等级满足配方要求。
3. 提供物品/流体原料以及足够的 AE 能量。
4. 保持输出通道可用。
5. 先用一个线程测试，再派发大批量任务。

## 线程生命周期

每个被接受的任务会占用 27 个持久化进程槽之一。进程槽会预留准确的输入资源键、记录能量消耗、
推进进度、准备确定性产物，并持续重试插入，直到存储系统接收产物。重载或失去 AE2 连接只会暂停进程槽，
不会丢弃其资源账目。

| 状态 | 含义 | 处理方式 |
|---|---|---|
| `RUNNING` | 能量和其他条件均满足 | 无需处理 |
| `PAUSED` | 线程通过自己的进程控制被暂停 | 准备好后恢复 |
| `PAUSED_NO_GRID` | ME 节点或网络不可用 | 恢复线缆、供电和区块加载 |
| `OUTPUT_BLOCKED` | 已承诺的产物正在等待 | 释放匹配的 ME 存储容量 |
| `UNFORMED` | 结构不再匹配 | 扫描并修复高亮位置 |

## 安全扩展规模

普通模式最多接收 **27** 个并行任务；安全模式最多接收 **9** 个。达到允许的槽位上限后，
新请求会等待。即使限制或机器等级发生变化，已有的资源预留也不会被静默删除。
