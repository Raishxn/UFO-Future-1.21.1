# UFO Future 工具

UFO Future 提供可变形的能量工具，以及用于排查多方块结构问题的实用工具。

## 工具系列

- 消耗能量，而非耐久度
- 可在多种形态之间切换
- 变形时保留已存储的能量
- 拥有范围挖掘、自动熔炼或战斗强化等能力

## 主要形态

- **镐**
- **锤**
- **剑 / 巨剑**
- **斧、锹、锄、鱼竿、弓与法杖**

## 结构扫描仪

<ItemImage id="ufo:structure_scanner" scale="2" />

- 右键点击受支持的控制器以检查结构
- 高亮缺失或无效的方块
- 在聊天栏显示准确坐标与应放置的部件
- 创造模式下，**Shift + 右键**可自动搭建结构外壳
