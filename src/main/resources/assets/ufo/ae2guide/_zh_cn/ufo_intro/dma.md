# 次元物质装配器

<BlockImage id="ufo:dimensional_matter_assembler" scale="4"></BlockImage>

**DMA** 是 UFO Future 中的第一台高级机器。它能处理无序物品配方、可选基础流体、催化剂和热量管理。

## 核心循环
1. 将物品放入 9 格输入槽。
2. 仅在配方要求流体输入时填充**基础流体储罐**。
3. 在**冷却液储罐**中注入有效的冷却液。
4. 如果需要调整速度、效率或产出，可添加催化剂。
5. 供应 AE 能量，让 DMA 开始加工。

## 储罐
- **冷却液储罐**：不计入配方成本，仅用于移除 DMA 中的热量。
- **基础流体储罐**：由明确要求流体输入的配方消耗。

DMA 配方的常规流体输入不应要求冷却液。冷却液只能放入冷却液储罐。

## 冷却液发展流程
- **凝滞冷却剂**：每 **24 mB** 移除 **1 HU**，每 tick 最多 **1000 mB**。
- **稳定冷却剂**：每 **1 mB** 移除 **50 HU**，每 tick 最多 **10 mB**。
- **玻色-爱因斯坦凝聚态**：每 **1 mB** 移除 **200 HU**，每 tick 最多 **10 mB**。
- **液态星光**：实用性冷却液，每 **1 mB** 移除 **30 HU**，每 tick 最多 **10 mB**。

预期的发展路线是**凝滞 → 稳定 → 时间流体**。如果过早使用时序催化剂为主的配置，凝滞冷却剂将无法长时间维持。

## 热量与熔毁
- 工作时的基础产热：**每 4 tick +1 HU**，即施加催化剂热量倍率前为 **+5 HU/s**。
- 空闲时的被动散热：**每 40 tick -1 HU**，即 **-0.5 HU/s**。
- 热量低于 50%：运行稳定。
- 热量高于 50%：危险区域，会出现视觉警告效果并对附近造成伤害。
- 热量达到 100%：开始熔毁倒计时；如果未能及时冷却，机器将发生破坏性爆炸。

## 催化剂
- **物质流**：提升效率。
- **时序**：提高速度，但热量激增。
- **超流**：提高热稳定性。
- **量子**：专注于高级产出行为。
- **次元催化剂**：创造级覆盖。

## 当前定位
DMA 是入门级的灵活单机合成器。当配方变得极其昂贵，或需要基于样板的自动化吞吐量时，发展便进入多方块路线：

- **量子物质制造机**
- **量子切片机**
- **量子处理器组装机**
