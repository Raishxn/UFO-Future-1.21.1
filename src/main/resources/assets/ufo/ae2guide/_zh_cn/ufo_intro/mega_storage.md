# 巨型合成存储与协处理器

UFO Future 为 AE2 合成设施添加了容量极大的合成存储器与巨型协处理器。

- 超致密合成存储器
- 四维超立方合成存储器
- 视界地平线合成存储器
- 宇宙弦合成存储器

- 超致密协处理器
- 四维超立方协处理器
- 视界地平线协处理器
