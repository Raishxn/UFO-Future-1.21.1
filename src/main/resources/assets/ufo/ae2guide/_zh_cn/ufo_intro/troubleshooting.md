# 故障排查

## 结构无法成型

1. 对控制器执行扫描。
2. 检查控制器朝向以及所有被高亮的位置。
3. 对允许多种舱口或场等级的位置，查看 JEI 的替代材料。
4. 确保包含完整结构的所有区块都已加载。
5. 只有在安全断开活跃任务后，才替换可疑舱口。

扫描仪和查看器使用与结构成型相同的已编译结构定义。如果结果不一致，这就是值得报告的错误；
报告时请附上控制器坐标以及被高亮位置应放置的方块。

## `PAUSED_NO_GRID`

- 将线缆连接到舱口标示的连接面。
- 检查 AE2 频道和网络供电。
- 重新连接后确认结构仍然成型。
- 已存在的进程缓存会持久保存；不要仅为了重启而破坏控制器。

## 样板可见但任务没有启动

- 配方等级可能高于机器等级。
- 27 个进程槽可能已全部被占用。
- 所需的某种物品替代项、流体或化学品可能缺失。
- 进程可能被手动暂停。
- 安全模式可能因机器达到温度上限而阻止运行。

## `OUTPUT_BLOCKED`

为完全匹配的输出资源键释放容量。已接收的数量会从待输出记录中移除；
被拒收的数量会继续保存并稍后重试。输出等待期间，不要反复拆除和放回控制器。

## 机器过热

- 确认冷却液进入冷却通道，而不是配方流体通道。
- 将凝滞冷却剂升级为稳定冷却剂或时间流体。
- 减少活跃线程或关闭超频。
- 调整设施时启用安全模式。
- 检查催化剂的热量倍率。

## 数据包重载后

如果某个进程的配方 ID 已经消失，它会进入无效配方恢复流程。
当目标位置能够接收时，已记录的输入和缓存 AE 会被返还。如果存储已满，请腾出空间并等待控制器重试。
