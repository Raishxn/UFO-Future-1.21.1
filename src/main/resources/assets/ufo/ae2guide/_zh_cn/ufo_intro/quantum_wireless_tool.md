# 量子无线工具

<ItemImage id="ufo:quantum_wireless_tool" scale="4" />

首先使用源端的界面按钮，或手持工具潜行右键源，启用其无线模式。选中样板缓存器会自动启用其代理路由。

1. 右键量子样板缓存器、旧版量子样板舱口或[量子接口](quantum_interface.md)，以选择源。
2. 样板缓存器只能链接样板代理；旧版舱口只能链接 DMA。再次点击同一个目标面即可移除链接。
3. 潜行右键源，可在有线/无线模式之间切换，也可以使用其界面按钮。

手持工具时，蓝线会将所选源与蓝色的目标面连接起来。黄色立方体标识所选源，黄色预览则标示准星下的新面。源加载期间，链接会自动刷新。HUD 也会显示源、坐标和维度。线缆总线形式的量子图案提供器目前不能作为无线源。

对于处理样板，请链接机器的物品/流体输入面。合成产物仍需要一条返回 ME 存储的路径，例如使用链接到输出面的量子接口的自动导入。无线不会加载区块，也不会桥接维度/网络。替换目标会使其旧链接失效。

原始的 16×16 工具纹理属于 UFO 的视觉设计，并未复用 AE2 Lightning 的工具纹理。侧边栏组件署名仍归 AE2 Lightning Tech 所有。

<RecipeFor id="ufo:quantum_wireless_tool" />

每个源的默认范围为 32 格，可在缓存器/舱口/接口界面中调整。参见[无线网络与增益](quantum_wireless_buffs.md)。
