# UFO Future

**UFO Future** 将应用能源 2 的终局内容扩展至高级物质合成、并行量子工厂、
天文级存储以及恒星模拟。

![UFO Future](../pic/logo.png)

本指南说明当前 1.21.1 版本中实际实现的机制。精确配方请以 JEI 为准；
数据包和服务器配置可能改变材料消耗，但机器的工作流程保持不变。

## 已翻译的核心内容

- [量子物质制造机](qmf.md) — DMA 的大规模多方块进阶机器。
- [量子切片机](quantum_slicer.md) — 批量制作压印部件。
- [量子处理器组装机](quantum_processor_assembler.md) — 完成大规模处理器装配。
- [恒星联结](stellar_nexus.md) — 终局恒星模拟平台。
- [巨型合成存储与协处理器](mega_storage.md) — 扩展 AE2 自动合成容量与并行能力。
- [封存机制](containment.md) — 安全处理危险物品和流体。
- [UFO 工具](tools.md) — 可变形能量工具与结构扫描仪。

## 发展路线概览

1. 建立供电正常的 AE2 网络，并制作第一批 DMA 组件。
2. 使用 <ItemLink id="ufo:dimensional_matter_assembler" /> 处理灵活的物品/流体配方、催化剂以及早期恒星物质。
3. 建造通用多方块生产线，并连接 <ItemLink id="ufo:quantum_pattern_hatch" /> 以使用 AE2 处理样板。
4. 将恒星场生成器从 MK1 升级至 MK3，以解锁配方并加速低等级生产。
5. 扩建合成 CPU 与存储系统，以承载超大规模请求。
6. 建造 <ItemLink id="ufo:stellar_nexus_controller" />，进行终局恒星模拟和长周期生产。

> 已停用的熵装配矩阵现由量子计算枢纽、量子样板制造矩阵与无限制造奇点组成的自动合成生产线取代。
