# 恒星联结的安全、超频与恢复

安全模式默认开启。它会将能量、燃料和冷却液消耗乘以 **2.5**，但达到最高温度时会执行受控停机。
超频提供 **5 倍速度**，同时消耗 **10 倍 AE**，并承受 **5 倍燃料、热量和冷却液负荷**。

关闭安全模式后，达到最高温度会触发服务器配置的局部封存故障。
破坏性方块损伤默认关闭；即使管理员明确启用，仍受半径、每 tick 工作量、总方块预算和维度白名单限制。

## 恢复表

| 症状 | 可能原因 | 恢复方式 |
|---|---|---|
| 结构无效 | 场生成器缺失/混用，或舱口数量错误 | 扫描并修复准确的高亮位置 |
| 能量没有增加 | 能量舱口缺少外部 FE 供应 | 检查 FE 线缆、供电方和舱口储能 |
| 启动被拒绝 | 配方条件、燃料、AE 或输出不可用 | 阅读控制器显示的验证信息 |
| 热量上升过快 | 冷却液不足/过弱，或启用了超频 | 关闭超频、升级冷却液并保持安全模式 |
| 输出持续等待 | ME 容量或分区拒绝该资源键 | 恢复匹配容量；不要重新启动配方 |
| 重载后离线 | 部分结构或区块不可用 | 加载完整结构并等待状态协调完成 |

新配方的第一个周期，或刚刚修改场等级、冷却液管路、服务器热量配置之后，绝不要关闭安全模式。
