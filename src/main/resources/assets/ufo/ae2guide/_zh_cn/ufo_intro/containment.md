# 安全封存与以太胶囊

这两种容器都只有一个槽位，专门用于存放被标记为危险的资源。

## SCM — 危险物品容器

1. 一只手持安全封存物质（SCM），另一只手持一组危险物品。
2. 使用 SCM，将整组物品存入其内部的唯一槽位。
3. 取出时，让另一只手保持空置并再次使用 SCM。

工具提示会显示其中封存的物品。非危险物品会被拒绝。

## ACC — 危险流体容器

以太封存胶囊（ACC）最多可存储 **4,000 mB** 带有 UFO 危险流体标签的流体。

1. 两只手分别持有 ACC 和另一个流体容器。
2. 正常使用，将另一个容器内的危险流体转移进 ACC。
3. 潜行使用，可将最多 1,000 mB 流体从 ACC 转移到另一个容器。

ACC 会拒绝没有对应标签的流体，也绝不会把不同流体混入已经装有流体的胶囊。
配方材料和标签可由整合包调整；当前制作方式请以 JEI 为准。
