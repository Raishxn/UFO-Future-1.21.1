# 基础设施

本节介绍让 UFO 机器融入 AE2 工厂的各种方块：场等级、样板派发、定向舱口、
大型合成 CPU 和能量缓存。

<SubPages />

## 可靠工厂检查表

1. 按照方块朝向所示的连接面接入每个定向舱口。
2. 让控制器和舱口位于同一个已供电网络中。
3. 提供足以容纳完整请求的合成存储容量。
4. 为已承诺产物和概率副产物预留存储空间。
5. 升级所有必需的场生成器位置；一个较低等级的场就可能降低整台通用机器的等级。
